# 预定训练—读出口径匹配对照

本实验复用全部5344个合格窗口、6场已曝光DFL比赛、5个种子及835个冻结分片。前1.8秒为旧均值路径，末0.2秒为原16条随机续接；不生成新轨迹，不读取WC2018、Metrica或保留比赛标签，不启动50轮。

唯一新增方法为30个MC匹配DirectWith头：每个种子×外层留出比赛一个。每次训练仅接收其余五场的明确行切片、原等比赛权重和Y10/Y2标签。36维原始特征、冻结旧均值特征标准化器、36个缺失标志、tanh8及两个直接输出共602参数不变。复制相应旧头保存的initial参数，使用全新空Adam状态；不从训练完的均值头续训。旧标准化器仅由原训练五场均值特征计算，本轮不重估。

每个窗口、每个输出先平均16个概率，再计算标签的负对数概率。以logsumexp分别平均p与1−p，保持Y10 BCE与Y2 BCE系数均为1，最后加0.005×所有权重平方和（不惩罚bias）。不是平均粒子BCE、平均logit或重复16个标签。Adam lr0.003、betas(0.9,0.999)、eps1e−8、weight_decay0，全批200步，合计梯度后全局范数裁剪10；每步只有一次optimizer.step。CPU float64单线程，保存全部训练史与Adam终态，不做早停或持出loss监视。

全部30个权重封存后，进行2×2读出：旧均值训练/新MC训练 × OldGPUmean/K16概率平均。OldGPUmean是旧头真实训练口径；CPUmean仅作为已封存后端桥接说明，不新增方法。旧头与旧Direct运输读出要逐项重算核验，保留既有负结果。

两个共同主要对比：A=新MC训练/MC−旧均值训练/MC，检验目标匹配；B=新MC训练/MC−旧均值训练/OldGPUmean，检验基线替代。主指标为Y10 log loss；次要报告Brier、每场绝对平均概率偏差、有符号风险漂移、Y2指标、Early>Y10违例、冻结标准化器下特征异常和缺失、粒子数值MCSE。固定报告全部四格、5种子、6比赛和所有负值，另报告Ψ=(新MC−新Mean)−(旧MC−旧Mean)及配对均值概率变化。Ψ仅是已曝光总体的描述性目标×读出交互，不是因果机制确认。

每场先平均全部窗口，再等权平均六场；5种子是配对初始化流程，16粒子不是独立样本，6000更新不是新增数据。保持历史CV_Direct_WithEarlyBCE强基线原值。网络容量和更新次数相同，但MC每步16倍头输入计算；不声称等计算量。所有30头封存前禁止持出预测/评分；预测全部封存后才对持出标签评分。文件内全标签向量可能物理解码，训练函数只收到白名单切片；明确记录此限制。

结局为固定t0球队A在(t0,t0+10]的提供商记录ShotAtGoal，不是进球，不是干预效果。既有AUTHOR3_PLUS_DIRECT_OTHER4时钟/事件映射沿用，不宣称新独立时钟认证。零合格窗口第七场WOH保留，不补成负例。

预算：CPU1，生产阶段合计1200秒、512MiB输出；新拟合恰好30×200，无自动重试、无结果驱动改方案。来源、行号、标签、概率恒等式、重复粒子梯度或旧头复算失败即停并保留失败现场。先通过手工K1/K16重复粒子、非相同粒子有限差分及权重/正则/裁剪检查，再由根代理精确锁定source/plan授权执行。失败或未稳定时仍保留原代码结果，不追加50轮。
