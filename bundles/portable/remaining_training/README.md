# Remaining fixed-result reproduction delivery

This local code candidate contains Table4 training, the retained A dependency,
Table7 factorial/Qfirst training, Table8 saved-world transfer/calibration, and
S4/S5 computations. See each module README for the exact input boundary.
Directory `table8` is the Qfirst component of current manuscript Table7;
`table8_native` is current manuscript Table8. Naming history does not change
the displayed-table mapping.

No source data, model snapshots, tokens or failed input trees are packaged.
`table7/inputs` contains only three manifest/binding/reference metadata JSONs;
it is not the private input bundle. Other modules use `metadata/` or a pinned
contract. Reassembling authorized cached inputs is distinct from reconstructing
all raw data. These files are a local review candidate, not a public release or
a determination of redistribution/license rights.

The Chinese report and completion/index JSON describe actual computations,
preserved adverse outcomes, exactness tests and outstanding work. No experiment
in this delivery establishes causal action benefits or new independent data.
