# Additional retained computation routes

Recommended code directories:

- `preprocessing_v2`: pinned raw SkillCorner/Metrica sources to retained trajectory inputs and recovered position truth.
- `table3`: original four-epoch, three-arm, five-seed neural training from deterministic random initialization.
- `table6_v2`: saved trajectory arrays and same-window recorded kinematics to the complete 13-table diagnostic output and current Table 6.

Each directory has explicit CLI instructions, dependencies, source lineage and input hashes. Outputs are placed in new directories. The previous versions, interrupted execution receipts, old code, old weights and old numerical results remain unchanged.

The separate retained-inference package supplies Table 3/4 frozen inference and earlier Table 5/9/10/supplementary routes. This package adds upstream raw preparation and Table 3 training; it does not silently replace the earlier bundle. The local validation directory contains actual execution/parity evidence, not distributable third-party data.

Current source-chain completion is narrower than whole-paper completion. Table 4 training, Table 7/8 computation ports and remaining world-generation dependencies require separate work. Data/weight redistribution rights, actual public release and final synchronized submission documents remain open. No new 50-epoch run, external-test tuning, real intervention benefit or whole-CCPV superiority is claimed.
