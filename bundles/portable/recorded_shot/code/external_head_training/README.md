# 固定部署头的训练重建（本地待发布代码）

此入口重建外九实验使用的三个球员状态风险模型 × 五个种子：G_shared、GM200_shared、GM_OLS1s。它从已冻结的六场开发比赛特征缓存重做原定200次CPU优化，不是新的实验、参数搜索或50轮神经网络训练。外九比赛已经曝光，重复执行不能称为新的盲外验。

## 输入和运行

需要由合法途径获得的原始开发特征缓存 `features.npz`，SHA256为 `b5f94c95aa8d14d60a1b7d5600e2b6a6f090e81b4a64958ee0aa2f8dd8528d07`，2,803,791字节。代码包不包含该缓存、逐窗标签、训练索引或模型权重，也不提供令牌。获取与再分发许可尚需作者落实，不能仅凭本脚本从互联网取得该文件。

原数值环境为Python 3.11.5、NumPy 1.26.4、CPU float64和单线程BLAS。其他系统或BLAS可能产生末位差异，不能预先保证逐位相同。

```text
python train.py --features /authorized/path/features.npz --output /new/path/rebuilt_heads
```

输出目录必须不存在。命令保留每个模型的权重、Adam状态、初值、全部200步历史、训练索引和标准化参数；这些是运行时在用户私有目录生成的衍生物，不在本代码包内。输出`PAUSE_REQUESTED`可在下一个模型开始前停止，已有结果保留。

## 不变的实验定义

- 六场DFL比赛、11,542候选、9,483可训练窗口、363阳性窗口；窗口不是独立事件。
- 每场等权1/6，场内均匀；仅native条件训练。三模型共同13维几何/支持特征，后两者增加3维运动特征。
- 标准化与缺失均值填补仅取开发训练行；共享13维标准化完全相同。
- 原定随机初始化、200步Adam、学习率0.003、betas=(0.9,0.999)、eps=1e-8、权重ridge=0.005、不罚截距、全局梯度范数上限10。
- `training_math.py`中的NAMES及四个数学函数从已执行的原代码逐段原文提取。来源及片段哈希见`source_provenance.json`。

## 复现范围与尚未完成事项

此包实现的是“冻结特征缓存→15个部署头”，不是“原始DFL轨迹/事件→完整CCPV论文”。上游原始数据提取及事件映射入口仍需与合法输入路线一起整理。不能把从缓存成功重建称为原始数据端到端复现。

模型冻结清单的`FROZEN_ALL_15_BEFORE_READOUT`只表示本次重建先保存所有模型、后执行读出；它不表示外九资料仍未曝光。权重数组是否重现原模型必须独立比较，程序不会自行作此声明。
