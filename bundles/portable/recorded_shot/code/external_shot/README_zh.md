## 内容与输入边界

- 五个原数值模块逐字节保留，数学、端点、资格规则、固定头和宏观评分不变。pipeline.py只添加显式路径、完整队列检查、create-only阶段输出和冻结/重放核验。
- fixed_inputs.json仅含预定九场、十八半场GSR/九个BAS相对文件名、字节数/SHA256、原生时钟/坐标contract、缓存/模型/原结果的哈希及推断参数指纹。无逐窗坐标、标签、训练索引、权重或凭据。
- 原始数据、十八批缓存、十五个head NPZ和head_freeze.json均未打包。使用者必须自行取得合法授权；不会下载任何数据。
- 15头NPZ的原格式含训练历史/索引，加载器只读取用户显式提供的文件并核验其结构，不会把它们写入代码包。不得据本包推断训练数据已公开。
- 保留的frozen_predict.py有历史兼容默认路径；新CLI从不使用它，--head-manifest必须明确提供。
- 所有资料已经曝光。本次重建或重放的冻结只保证“先保存预测，再开BAS评分”的软件边界，不构成新的盲外验，不能重新选九场、选模型或校准。

## 实跑命令

以下占位符需替换成使用者实际授权路径；不要使用本机隐式默认。每次--out必须是全新目录，且位于代码包外。失败/部分输出保留；不得在原目录补写或覆盖，需使用新的尝试目录。

1. 原始GSR→完整cohort→冻结预测（将顺序流读全部18个大文件；本轮交付未重跑该原始入口）：

    python -B pipeline.py predict --data-root "<授权数据根目录>" --head-manifest "<授权模型目录>/head_freeze.json" --out "<新运行目录>/prediction"

2. 已授权完整特征缓存→cohort→冻结预测（本轮实际验证的快速入口，不读原始GSR）：

    python -B pipeline.py replay --feature-root "<授权缓存目录>" --head-manifest "<授权模型目录>/head_freeze.json" --out "<新运行目录>/prediction"

若使用重建manifest，在上述命令追加：

    --head-manifest-sha256 "<该manifest的完整SHA256>"

每个入口都会输出prediction_freeze.json及其SHA256。冻结之前不读BAS。全部候选保留，未来时钟不完整的行仍预测。

3. 独立评分阶段：

    python -B pipeline.py score --data-root "<授权数据根目录>" --prediction-root "<新运行目录>/prediction" --freeze-sha256 "<上一步打印的SHA256>" --out "<新运行目录>/score"

此阶段先验证冻结收据、所有18批缓存、完整cohort与预测哈希，再打开9个BAS。不加载head、不重新推断、不重训。输出完整候选标签、未知原因、全seed/fixture/macro/配对指标；完成后再次验证预测未改。

4. 与原冻结结果全量比较：

    python -B pipeline.py verify --prediction-root "<新运行目录>/prediction" --score-root "<新运行目录>/score" --reference-prediction-root "<原冻结预测目录>" --reference-score-root "<原冻结评分目录>" --out "<新运行目录>/comparison"

对原参考文件先验哈希核验后，比较所有row key、252705个头概率、16847个固定先验、16847个候选标签/未知原因及完整评分树，保留逐值相等标志和最大差值。verify不读取原始GSR或模型。

## 固定科学契约

半场原生anchor=40*(g-1)毫秒，25Hz，shift=0；原始旧raw第二半场映射失败不被修复或替换。候选为first_frame+24+75k；六点同身份历史在-25,-20,-15,-10,-5,0帧，共支持的200ms与OLS1s读出。有限且唯一player/goalkeeper参与；不加入BALL、球队或完整22人条件。

主要结局只采用字面Shot/SHOT在(t0,t0+10000ms]的记录；Goal/Header/Block不并入。完整251帧future-clock支持、未知字面标签和无法定位事件规则由原模块执行；未知=-1，不当阴性，也不因窗口中另有Shot而抢救。来源真实事件完整性不由这些软件检查保证。

所有九场先场内均值再等场宏观，五种子SD是初始化变异；缺比赛支持时完整九场汇总为NA。16,847候选/16,789已知/58未知/782阳性为既有结果边界，阳性是重叠窗口数，不是独立射门次数。本包不用于再次调参，也不涉及WC2018或新的50轮训练。
