# 当前 v10 补充表 S3 / S4 / S5 / S7：保存结果重聚合

本目录提供可搬迁、仅 Python 标准库的独立入口。它从 27 份固定 CSV/JSON 保存结果重新聚合或核对当前表和分母；不拟合模型、不运行神经网络、不读取原始 GSR/BAS/XML、轨迹 NPZ、权重或 SQLite。它不是完整训练/推断生成级复现。原文件保持不变。

## 运行

需要 Python 3.11。使用者自行合法取得 `input_contract.json` 所列文件，在明确输入根目录下保持其相对文件布局。配置只有文件名、bytes、SHA 和来源，不附结果数据；输入 JSON 内历史本机路径不会被追踪打开。27 份输入合计 2,851,666 字节。

```powershell
python -B .\build.py --input-root "$InputRoot" --output "$NewOutputDir" --manuscript "$CurrentV10SupplementMarkdown"
```

`--output` 必须尚不存在，并位于代码包外。所有 writer 独占新建，不覆盖旧文件。可以省略 `--manuscript` 仅生成；提供时只在结果生成计算之后核对固定当前 v10，绝不从文稿读取数字来生成表。文稿和输入均有精确 SHA 约束。

输出包括四张表的 CSV、`tables.md` / `tables.json`、`denominators.json`、S3 全 56 端点的 `S3_all56_reaggregated.json`，以及逐格核对和完成记录。没有临时修改、剔除不利种子或失败窗的路径。
